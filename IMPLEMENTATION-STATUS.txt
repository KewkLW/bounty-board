NEW ENDPOINTS

GET  /api/agents/status/active       → List only active agents
GET  /api/agents/status/all          → List all agents with status
GET  /api/agents/:id/status          → Get specific agent status
POST /api/agents/:id/status          → Update agent status
POST /api/agents/:id/deactivate      → Deactivate agent (conductor)
POST /api/agents/:id/reactivate      → Reactivate agent
GET  /api/agents/:id/events          → Get agent status history

AGENT STATUS STATES

🟢 ONLINE   - Connected, ready to work
🟡 ACTIVE   - Currently working on a bounty
🔵 IDLE     - Online but waiting for work
🔴 OFFLINE  - Disconnected or deactivated

CONDUCTOR COMMANDS

List agents:
  node conductor.js list active          # Active agents only
  node conductor.js list all             # All agents

Agent details:
  node conductor.js status <agentId>     # Specific agent
  node conductor.js history <agentId> [n] # Status change history

Manage agents:
  node conductor.js deactivate <agentId> # Take offline
  node conductor.js reactivate <agentId> # Bring online

QUICK START

1. Launch System:
   start-all.bat

2. View Dashboard:
   http://localhost:3777/agents

3. Monitor with CLI:
   node conductor.js list active

4. Create Work:
   node bounty-cli.js create "Task" --type task --tier C
